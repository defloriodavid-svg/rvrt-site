FORMA DENTAL STUDIO — TEMPLATE PREMIUM

SCELTA COMMERCIALE
Il template è pensato per studi dentistici indipendenti e poliambulatori locali.
È una nicchia ad alto valore percepito, adatta a preventivi superiori rispetto a barber,
centri estetici e piccole attività retail.

APERTURA LOCALE
Estrai lo ZIP e apri index.html con doppio clic.
CSS, JavaScript, favicon e pagine interne usano percorsi relativi.

PUBBLICAZIONE SU VERCEL
1. Estrai lo ZIP.
2. Carica tutti i file nella root di un repository GitHub.
3. Importa il repository su Vercel.
4. Framework Preset: Other.
5. Build Command: vuoto.
6. Output Directory: vuota.
7. Deploy.
