LEGACY BARBER — VERSIONE PRONTA PER VERCEL

PUBBLICAZIONE RAPIDA
1. Estrai questo ZIP.
2. Crea un nuovo repository GitHub.
3. Carica TUTTI i file presenti nello ZIP direttamente nella root del repository.
   index.html deve essere visibile subito, non dentro una sottocartella.
4. Su Vercel seleziona Add New > Project e importa il repository.
5. Framework Preset: Other.
6. Root Directory: lascia vuota.
7. Build Command: lascia vuoto.
8. Output Directory: lascia vuoto.
9. Premi Deploy.

PERSONALIZZAZIONE PRIMA DI CONSEGNARLO
- In index.html cerca 39XXXXXXXXXX e sostituiscilo con il numero WhatsApp completo.
  Esempio italiano: 393519927137, senza +, spazi o trattini.
- Cambia nome attività, indirizzo, orari, prezzi, testi e membri dello staff.
- Sostituisci le immagini dimostrative con fotografie autorizzate del cliente.
- Dopo aver collegato un dominio personalizzato, puoi aggiungere canonical, sitemap.xml
  e Open Graph image con l'indirizzo definitivo.
