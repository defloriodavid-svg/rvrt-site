NOCTURNE TATTOO — PREMIUM FULL VERSION

PRONTO PER VERCEL
Questo progetto è statico e non richiede npm, Node.js o build.

PUBBLICAZIONE
1. Estrai lo ZIP.
2. Carica tutti i file nella root di un repository GitHub.
3. Su Vercel: Add New > Project.
4. Importa il repository.
5. Framework Preset: Other.
6. Root Directory: vuota.
7. Build Command: vuoto.
8. Output Directory: vuota.
9. Deploy.

NOTA PERFORMANCE
Le immagini demo sono caricate da Unsplash e GSAP da CDN.
Per un punteggio Lighthouse definitivo superiore a 90:
- scaricare e comprimere le immagini reali in AVIF/WebP;
- ospitarle localmente;
- misurare il sito sul dominio definitivo;
- aggiornare canonical, Open Graph e sitemap.
Il punteggio non può essere garantito senza test sul deploy reale.

APERTURA LOCALE
Questa versione usa percorsi relativi: puoi aprire index.html direttamente con doppio clic e CSS/JavaScript vengono caricati correttamente.
