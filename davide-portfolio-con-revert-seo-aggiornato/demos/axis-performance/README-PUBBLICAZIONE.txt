AXIS PERFORMANCE — TEMPLATE PREMIUM

PERCHÉ QUESTA NICCHIA
Il template è pensato per personal trainer, performance coach, preparatori atletici
e piccole palestre boutique. È facile da adattare e il modulo candidatura rende
il sito orientato alla conversione, non solo alla presentazione.

APERTURA LOCALE
Estrai lo ZIP e apri index.html con doppio clic.
CSS, JavaScript e pagine interne usano percorsi relativi.

PUBBLICAZIONE SU VERCEL
1. Estrai lo ZIP.
2. Carica tutti i file nella root di un repository GitHub.
3. Importa il repository su Vercel.
4. Framework Preset: Other.
5. Build Command: vuoto.
6. Output Directory: vuota.
7. Deploy.
